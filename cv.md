##  Code Example
### Bubble Sort (C++)
Bubble sort is a simple sorting algorithm that repeatedly steps through the array
compares adjacent elements, and swaps them if they are in the wrong order.
The largest elements gradually move to the end of the array.

```cpp
#include <iostream>
using namespace std;

int main() {
    int arr[] = {5, 2, 9, 1, 3};
    int n = 5;

    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }

    for (int i = 0; i < n; i++) {
        cout << arr[i] << " ";
    }

    return 0;
}
```
